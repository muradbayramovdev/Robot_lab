Haqqımda

Salam! Mən robototexnika, elektronika və innovativ texnologiyalara böyük marağı olan gənc layihə tərtibatçısıyam. Rusiyada anadan olmuşam və hazırda fəaliyyətimi Azərbaycanda davam etdirirəm. Təxminən 4 ildir robototexnika dünyasındayam, son 2 ili daha sistemli tədqiqatlara həsr etmişəm. Həm elektronika, həm proqram layihələri üzərində çalışaraq mühəndislik bacarıqlarımı, alqoritmik düşüncəmi inkişaf etdirmişəm.

Layihələrim
LineBot 3000 Arduino Uno
Avtomatik xətt izləyən robot. İki IR sensor + PID idarəetmə. Məktəb yarışı üçün inşa edilib.
C++ PID IR Sensors DC Motors
ArmBot MK1 Arduino Mega
3-DOF lazer kəsilmiş akril qol robotu. EEPROM-a yazılmış hərəkət ardıcıllığı ilə avtomatik oynatma.
Servo EEPROM 3D Print Joystick
SonarRover ESP32
Wi-Fi üzərindən idarə olunan maneə aşma roveri. HC-SR04 sonar + daxili veb server.
ESP32 Wi-Fi Ultrasonic Web Server
Gələcək Hədəflərim

Robototexnika və proqramlaşdırma sahəsində daha qlobal layihələrdə iştirak etmək, peşəkar mühəndislər və mentorlarla tanış olmaq, startap layihələri həyata keçirmək.
