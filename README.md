# 🤖 Robot Lab

**Robot Lab** — robototexnika və müxtəlif texnoloji həlləri bir araya gətirən, praktiki biliklərin tətbiqi və inkişafı üçün hazırlanmış fərdi öyrənmə və nümayiş (learning & showcase) layihəsidir.

## 🚀 Canlı Sayt (Live Demo)
Saytı onlayn olaraq buradan izləyə bilərsiniz: [robo-lab.netlify.app](https://robo-lab.netlify.app/)

## 🛠 İstifadə Olunan Texnologiyalar
* **HTML5** — Struktur və səhifə tərtibatı
* **CSS3** — Dizayn, vizual üslublar və rəsmiləşdirmə
* **JavaScript** — İnteraktivlik və dinamik funksionallıq
* **Netlify** — Veb-hostinq və deploy prosesi
